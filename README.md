# QR Decomposition Algorithms and Applications

Pure computational implementation of orthogonalization and matrix decomposition methods from scratch, without relying on built-in functions.

**Tech Stack:** `MATLAB`

## About the Project
This repository contains a modularized code architecture for performing QR decompositions along with s a collection of usage examples for some of the auxiliary functions, tackling complex mathematical problems through two fundamental algorithms:
* Decomposition via the **Gram-Schmidt process**.
* Decomposition via **Householder reflections**.

In addition to the core algorithms and auxiliary functions for rank, and basis management, the project includes practical implementations for:
1. Matrix eigenvalue estimation.
2. Least squares solutions for overdetermined systems of equations.
